## 3. TML Publisher: Google and YouTube data
TML Publisher is our internal tool for uploading TML's own approved videos to **TML's own YouTube channel**. It is used only by Two Market Ledger's owner. It is not offered to the public, and it does not access anyone else's Google account.

**What it accesses.** When the owner signs in with Google and grants permission, TML Publisher uses the YouTube Data API (YouTube API Services) with the scope needed to upload and manage videos on the TML channel (`https://www.googleapis.com/auth/youtube.upload` [plus `youtube.readonly` if used to confirm upload status]). It uses this permission only to:
- upload TML's own video files;
- set their titles, descriptions, privacy status and scheduled publication time;
- confirm that they processed and published correctly.

**What it stores.** An OAuth refresh token for the TML channel, kept in a restricted file on our own server that only the publishing service can read. We also store the video ID, upload status and publication time of our own videos, for duplicate prevention and reporting. We do **not** collect, store or process any viewer's or other user's personal information, comments, subscriber lists or analytics about individuals.

**Sharing.** We do not sell, rent, share or transfer Google user data to anyone. We do not use it for advertising, and we do not use it to train artificial intelligence or machine learning models. It is used only to provide the upload function described above.

**Limited Use.** TML Publisher's use and transfer of information received from Google APIs adheres to the [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), including the Limited Use requirements.

**YouTube and Google terms.** TML Publisher uses YouTube API Services. By using it, users agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is described in the [Google Privacy Policy](https://policies.google.com/privacy).

**Revoking access and deletion.**
- Access can be revoked at any time on the Google security settings page, https://myaccount.google.com/permissions (also reachable at https://security.google.com/settings/security/permissions).
- When access is revoked, or on request, we delete the stored token within 7 days.
- Apart from the token, we keep only the IDs and status of our own uploaded videos, and no other YouTube API data. [Owner and counsel to confirm how the YouTube API Services 30-day refresh rule applies to these records.]

**Cookies.** TML Publisher runs on our server and in a one-time sign-in on the owner's own computer. It does not place cookies or similar technologies on any user's browser or device.
