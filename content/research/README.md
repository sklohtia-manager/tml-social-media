# Shared research record (all editions, website, YouTube and TikTok topic research)

Live file: Project file `claude/ledger-daily/research.md` (Projects tool; if unavailable, Buffer history is the fallback record). Read it first in every run; append, never duplicate. Policy: `ops/PUBLISHING_POLICY.md` §5.

| Column | Content |
|---|---|
| id | date + running number |
| headline | our own neutral headline |
| region / category | from `sources.json` regions and categories |
| event date | when it happened (Melbourne date; give the source's timezone if relevant) |
| publication date | when the source published it |
| source link(s) | original source URL(s) with publisher; second source if corroborated |
| verified facts | the specific facts (numbers with units and periods), attributed |
| economic relevance | why it matters; confirmed effects vs possible effects; Australia/India link only if real |
| evidence | routine (1 credible report) / official / corroborated (independent second source) |
| tier | A / B / C / D |
| access | ok / blocked (per source, this run) |
| publishing history | edition, channels, Buffer post IDs, website page, video IDs, date |

Rules: reuse a verified row for other platforms instead of re-researching; recheck fast-moving figures older than 24 hours; mark blocked sources and do not retry them in the same run; never record anonymous social posts, unverified blogs or AI summaries as evidence.
